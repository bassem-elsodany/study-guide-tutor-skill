The files that cover the whole course. You do not need to read them in order.

## The short version

1. Want to **practise**? Open [09-study-player.html](09-study-player.html) (double-click it).
2. Want to **test yourself** across both chapters? Take the [timed exam](07-exam.md); it is easier in the player.
3. After a session, send your results file to the tutor: it fills in your progress and the list of things to revisit.

## What each file is for

| File | What it is | Use it when | Contains answers? |
|---|---|---|---|
| [07-exam.md](07-exam.md) | one timed exam over both chapters | once both chapters are done | no |
| [08-exam-key.md](08-exam-key.md) | its key, with the chapter and slide of every question | only after you finish the exam | **yes** |
| [09-study-player.html](09-study-player.html) | the interactive page: quiz, flashcards, exam, progress | any time you want to practise | answers show after you choose |
