# Memorization Coaching

Use these techniques when the student asks how to retain the material, or when grading reveals repeated misses on recall-heavy questions. Teach the techniques by applying them to the student's own material — never as abstract study advice.

## 1. Anchor every rule to a real case

Abstract rules fade; stories persist. For each major rule or concept in the material, attach one named real-world case or vivid scenario. When the student later faces a question, the story retrieves the rule.

Apply it: go through the student's weakest topics and build a case-to-rule mapping table with them.

## 2. Learn the why behind every rule

A rule memorized as arbitrary text is fragile. A rule understood as the answer to "what went wrong that made this rule necessary?" can be re-derived under exam pressure even when the exact wording is forgotten.

Apply it: for any rule the student keeps missing, ask them "why does this rule exist — what failure is it preventing?" and fill the gap if they cannot answer.

## 3. Comparison tables for adjacent concepts

Exams live in the gaps between similar-looking things. For every pair or cluster of confusable concepts, build a table whose final column is "the one thing that separates them." The student should be able to reproduce that column from memory.

Apply it: whenever a graded block shows the student confusing two concepts, build the table immediately as part of the miss explanation.

## 4. The 3-layer pattern for frameworks and regulations

For any law, standard, or framework, lock in exactly three things:
1. **Who it applies to** (scope, roles, jurisdiction)
2. **What it requires** (the core obligations)
3. **What happens on violation** (penalties, enforcement)

These three layers answer the large majority of exam questions about any given framework. Depth beyond them is earned only after all three are solid for every framework in the material.

## 5. Group by theme, not by source order

Materials often present content by chapter, jurisdiction, or chronology. Memory works better by function: regroup items by what they protect, what problem they solve, or what family they belong to. Cross-cutting themes create multiple retrieval paths to the same fact.

Apply it: build thematic clusters with the student near the end of the material, once enough pieces exist to cluster.

## 6. Active recall over re-reading

Re-reading produces familiarity, which feels like knowledge and is not. Recall — closing the material and reproducing it — is what builds retention, and the struggle of recall is the mechanism, not a sign of failure.

Apply it: between blocks, run short closed-book challenges ("name the seven principles from memory"). What the student cannot reproduce is the precise study list; everything they can reproduce needs no more time.

## 7. Use built-in mnemonics only on request

If the material ships with mnemonics, they are available — but only when the student wants them. Some students retain through mnemonics; others find them noise. Ask once, respect the answer for the whole session.

## Scheduling advice (when asked)

- Short, frequent recall sessions beat long re-reading sessions.
- Revisit missed items on an expanding schedule: next day, then a few days later, then the week after.
- The final pre-exam pass is the revisit list from grading — missed concepts with their anchors — not the full material.
